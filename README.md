# Plants vs. Zombies

This folder contains the C# Crowd Control pack definition for **Plants vs. Zombies**.

## Connector and setup

`PlantsVsZombies.cs` selects `PCConnector` and has a `popcapgame1` version profile. Run that supported process before testing. No installer is included.

## Layout

- `PlantsVsZombies.cs` — memory-backed pack definition and effects.

## Development

Verify the `popcapgame1` profile and memory behavior whenever the game executable changes.
